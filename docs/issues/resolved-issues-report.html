One design decision worth noting. The token-identity fix (#2) revealed that errors.Is should match against a sentinel (a value carrying identity), not between two sibling derived errors. So matching is now by an opaque id that only Sentinel mints and that propagates through From/WithMessage — which also made the tag/cause behaviour uniform, resolving #5 for free.

1 · From(nil, …) panicked on .Error()

from-nil-cause-panic · error_cause.go, coalesce.go
FIXEDwas CRASH6 call sites

All five From builders plus the coalesce render dereferenced a nil cause.

Resolution
_ErrorWithCause.Error() now returns s.msg when the cause is nil (catches all five From paths at the render site), and _CoalesceError.Error() skips nil members. Regression: TestBuildersNilCauseClass (6 subtests, none panic).

2 · errors.Is false positive from message equality

is-message-equality-false-positive · error.go, error_cause.go, fault.go
FIXEDwas HIGH

Matching was by message string, so unrelated errors sharing text matched.

Resolution
Added an opaque id to _Error; only Sentinel mints one (atomic counter). _Error.Is now matches on id, and the message-matching _ErrorWithCause.Is was deleted so every type promotes the single identity-based Is. Identity propagates through From/WithMessage (which copy the embedded _Error). Regression: TestIsDoesNotMatchUnrelatedSameMessage, TestIsMatchesSameSentinelIdentity.

3 · .From() on a tagged fault dropped the tag

tagged-from-drops-tag · tagged_error.go
FIXEDwas MEDIUM

The derived error fell back to InternalFault, losing retry/HTTP-status classification.

Resolution
_ErrorWithTag.From now returns a tagged result carrying s.tag, so classification survives. Regression: TestTaggedErrorFromPreservesTag.

4 · _CoalesceError.From discarded members from errors.Is/As

coalesce-from-discards-members · coalesce.go
FIXEDwas MEDIUM

Members were flattened to a string, so errors.Is/As could no longer find them.

Resolution
The cause is now Coalesce(err, s), keeping both the new cause and the original members traversable. Regression: TestCoalesceFromPreservesMembers.

5 · _ErrorWithTag.Is was inconsistent with its cause base

tagged-is-inconsistent-with-cause · resolved via #2

Resolution
Subsumed by #2: deleting the type-specific Is means every type now promotes the same identity-based _Error.Is, so cause and tagged errors behave identically. Regression: TestIsConsistentBetweenCauseAndTagged.

6 · GetFullError duplicated every layer's message

Resolution

7 · Empty message produced malformed separators

errorwithcause-empty-msg-leading-separator · error_cause.go, stack.go
FIXEDwas LOW

"%s: %s" emitted a ": " even with an empty message, giving ": root" / "x: : root".

Resolution
_ErrorWithCause.Error() returns just the cause when its message is empty; Wrap adds no ": " decoration on an empty message (returns the cause / adds a bare stack). Regression: TestFromEmptyMessageNoLeadingSeparator, TestBuilderFromEmptyMessageNoDoubledSeparator.
