Each chunk exhausted at least two investigation avenues. Sibling consumers `ioc` and `jaml` were inspected and checked through a temporary Go workspace pointing at this checkout.

- **ST-1:** Stack capture stopped at 512 frames. The ancestry comparison treated truncated tails as complete roots, so wrapping or tagging a deeply created error replaced its origin with the attachment site. Existing deep coverage ended at 200 frames.
- **ST-2:** Recovery discarded a fixed number of stack frames, leaving `runtime.gopanic` at the raw trace origin. Direct calls outside a deferred panic path also lost the caller. Formatted traces hid the runtime-frame defect.
- **CO-1:** The earlier coalesced-member preservation fix bypassed the shared wrapping boundary. Calling `From` on a stackless group retained its errors but failed to capture a stack.
- **CP-1:** README described `MissingValue` as a sentinel even though its tested behavior is a stack-traced one-shot tagged error. Documentation also overstated mixed-tag detection in coalesced groups.
- **CP-2 (unresolved semantics):** `WithMessage(...).From(...)` replaces the decorated cause, including identity/tags held by that cause. Existing tests explicitly require cause replacement. This sweep preserves that behavior.

## Decisions

Accept complete stack capture and deliberate panic-boundary selection. Increasing the fixed cap again would retain the same failure class. Preserve the existing call-path ancestry heuristic and Frame/StackTrace representation. Independently review explicit and runtime panics, recovery helpers, nested panic boundaries, and direct-call fallback.

Accept reuse of the existing stack attachment boundary for coalesced `From`, including a nil incoming cause when the preexisting aggregate is still a non-nil cause. Preserve messages, every member, errors.Is/As traversal, and last-tagged-member precedence.

Reject `Unwrap() []error` because it would break `Fault`. Reject cached aggregate-prefix state or expanded Is/As scans without a measured performance need; combining full scans with prefix fallback could introduce quadratic traversal. No standalone sentinel identity redesign is justified by the evidence.

Preserve ambiguous cause-replacement semantics, dropping the attachment message for a nil cause, mixed-tag precedence, and the existing heuristic when separate goroutines have identical call paths. Correct the documented contract instead of changing tested constructor behavior.
